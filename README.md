# PDF Audio Reader for macOS

This Electron app allows you to:

- Select and view a PDF file
- Use macOS built-in voices to read the PDF aloud
- Control playback (start, pause, resume, stop)
- Skip to specific pages or select text to start reading from
- Choose voice and speed

## Getting Started

1. Install dependencies: `npm install`
2. Start the app: `npm start`

## Features

- Modern, simple UI
- PDF navigation and selection
- Uses macOS `say` or Speech Synthesis API
